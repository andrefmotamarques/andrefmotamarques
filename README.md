# Hi, I'm André Marques 👋

MSc student in **Data Science** at ISCTE – University Institute of Lisbon, interested in machine learning, NLP and forecasting.

I like turning messy real-world data into models and insights that can actually be explained: from sentiment analysis of product reviews to forecasting stock indices, clustering millions of chart entries with Spark and modelling 1.3 million tennis matches in MySQL.

### Tech stack

**Languages:** Python, R, SQL
**Machine learning:** scikit-learn, PyTorch, Hugging Face Transformers, caret
**Statistics and time series:** statsmodels, pmdarima, PCA and clustering in R
**Big data and databases:** PySpark (MLlib), MongoDB, MySQL
**Visualisation and BI:** matplotlib, seaborn, Plotly, ggplot2, Power BI

### Featured projects

All projects come from my MSc coursework. Most were team projects, and each README credits the team.

| Project | What it does | Stack |
|---|---|---|
| [Amazon reviews sentiment analysis](https://github.com/andrefmotamarques/amazon-reviews-sentiment-analysis) | Compares lexicons, classical ML, fine-tuned DistilBERT and GPT-4o for sentiment classification (best Macro F1 0.91) | Python, NLTK, scikit-learn, Transformers |
| [Norway stock index forecasting](https://github.com/andrefmotamarques/norway-stock-index-forecasting) | SARIMAX vs VAR vs LSTM using oil prices and the USD/NOK rate (LSTM MAPE 2.6%) | Python, statsmodels, PyTorch |
| [ATP tennis database](https://github.com/andrefmotamarques/atp-tennis-mongodb-mysql) | Cleans 1.3M ATP match records in MongoDB and models them as an 8-table relational MySQL database with full integrity constraints, then answers 4 questions in SQL | MongoDB, MySQL, SQL |
| [Billboard hits sound profiles](https://github.com/andrefmotamarques/billboard-hits-sound-profiles) | K-means on 2M weighted song-weeks to find how the sound of hits changed since 1958 | PySpark, MLlib |
| [Lisbon real estate prices](https://github.com/andrefmotamarques/lisbon-real-estate-price-prediction) | Random Forest pipeline predicting apartment prices in Lisbon (R² 0.89) | Python, scikit-learn |
| [Budapest Airbnb prices](https://github.com/andrefmotamarques/budapest-airbnb-price-prediction) | Linear regression vs Bagging, Random Forest and GBM in R | R, caret |
| [Quality of life in Portuguese municipalities](https://github.com/andrefmotamarques/portugal-municipalities-quality-of-life) | PCA and clustering on INE data to build a municipal quality-of-life index | R, psych, factoextra |
| [Hospital KPI dashboard](https://github.com/andrefmotamarques/hospital-kpi-dashboard-powerbi) | Executive Power BI report on hospital activity, length of stay, readmissions and costs, with a star-schema model and DAX measures | Power BI, DAX, Power Query |
